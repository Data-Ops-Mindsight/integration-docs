  • Acompanhamento ↗ acompanhamento.mindsight.com.br/mindsight/external/v1/docs/

  • Performance ↗ performance.mindsight.com.br/mindsight/external/v1/docs/
⚠
Importante: ATS e Mindmatch usam outra autenticação

As APIs do ATS e do Mindmatch não utilizam o fluxo descrito nesta página. Consulte a documentação específica desses produtos antes de integrar.

Para autenticar nessas quatro APIs, primeiro obtenha um Access Token utilizando o client_id e o client_secret fornecidos. O endpoint de autenticação é separado dos endpoints funcionais apresentados em cada documentação.

01 Informe as credenciais

Utilize o identificador e o segredo da aplicação.

02 Solicite o token

Envie uma requisição POST ao endpoint de autenticação.

03 Acesse a API

Inclua o token Bearer em cada requisição funcional.

Endpoint de autenticação

A URL de autenticação segue este padrão:

POST https://auth.{URL_BASE}/{CLIENTE}/o/token/

Para o ambiente Mindsight, utilize auth.mindsight.com.br e substitua {CLIENTE} pelo identificador recebido para sua organização.

Parâmetros enviados

application/x-www-form-urlencoded 
grant_type=client_credentials
client_id=SEU_CLIENT_ID
client_secret=SEU_CLIENT_SECRET

Exemplo em Python

O exemplo abaixo utiliza a biblioteca requests e interrompe a execução caso a API retorne um status HTTP de erro.

Python 
import requests

CLIENTE = "SEU_CLIENTE"
client_id = "SEU_CLIENT_ID"
client_secret = "SEU_CLIENT_SECRET"

url = f"https://auth.mindsight.com.br/{CLIENTE}/o/token/"

payload = {
    "grant_type": "client_credentials",
    "client_id": client_id,
    "client_secret": client_secret,
}

headers = {
    "Content-Type": "application/x-www-form-urlencoded",
}

response = requests.post(url, data=payload, headers=headers)
response.raise_for_status()

access_token = response.json()["access_token"]
print(access_token)

Utilizando o Access Token

Após obter o token, envie-o nas requisições aos endpoints da API por meio do header Authorization:

Header HTTP 
Authorization: Bearer {access_token}

Exemplo de consulta

Python 
api_url = "https://URL_DA_API/ENDPOINT"

api_response = requests.get(
    api_url,
    headers={
        "Authorization": f"Bearer {access_token}",
        "Accept": "application/json",
    },
)

api_response.raise_for_status()
dados = api_response.json()

Boas práticas de segurança

O client_secret identifica sua aplicação e deve ser tratado como uma senha. Armazene-o em uma variável de ambiente ou em um gerenciador de segredos.

⚠
Não exponha suas credenciais

Nunca inclua um client_secret real em HTML público, JavaScript do navegador, notebooks compartilhados ou repositórios Git.
