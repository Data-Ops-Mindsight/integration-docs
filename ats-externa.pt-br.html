API Externa do ATS

Guia de Integração: Oportunidades e Contratados

Um guia prático para integrar o seu sistema ao ATS de Recrutamento da Mindsight: autenticar com par de chaves, listar e criar oportunidades, ler os campos expansíveis (como a requisição de vaga) e consultar os contratados. Tudo foi validado com chamadas reais.

Visão geral

A API externa do ATS de Recrutamento da Mindsight permite que o seu sistema leia usuários e oportunidades (vagas), crie novas oportunidades e consulte os candidatos contratados de cada uma delas.

ⓘ
Esta página é diferente do guia do MindMatch

O MindMatch usa o host app.mindsight.com.br e um event journal. A API do ATS descrita aqui usa o host recrutamento.mindsight.com.br, é por tenant (cada empresa tem o seu prefixo) e tem um conjunto próprio de endpoints. As duas usam o mesmo tipo de autenticação (JWT-bearer), mas com client_id, aud e URL de token diferentes.

Endereço base

URL base 
https://recrutamento.mindsight.com.br/{tenant}/external-api/v1/

Troque {tenant} pelo prefixo da sua empresa (informado pela Mindsight). A barra final (/) é obrigatória: sem ela o servidor não devolve JSON (veja Comportamentos observados).

Endpoints

1. Gere seu par de chaves

Você assina as requisições de autenticação com a chave privada; a Mindsight as verifica com a chave pública, que você envia antecipadamente. Em troca, recebe um client_id (UUID4), por exemplo 60955d10-6c30-4e73-bb2c-c9878b59007d.

Shell (OpenSSL) 
openssl genrsa -out private.pem 2048
openssl rsa -in private.pem -outform PEM -pubout -out public.pem
⚠
Envie a chave pública, guarde a privada

Só o public.pem vai para a Mindsight. O private.pem nunca sai do seu ambiente e não deve ir para o git.

2. Autentique

O fluxo é OAuth 2.0 com Private Key JWT (RFC 7523): você monta um JWT chamado client_assertion, assina com a chave privada (RS256) e o troca por um access token.

1. Monte o client_assertion

Cabeçalho 
{
  "alg": "RS256",
  "typ": "JWT"
}
Corpo (claims) 
{
  "iss": "YOUR_CLIENT_ID",
  "sub": "YOUR_CLIENT_ID",
  "aud": "https://recrutamento.mindsight.com.br/",
  "iat": 1758000000,
  "exp": 1758003600,
  "jti": "92ceb8f8-0ff7-479b-833e-87d99fc53185"
}
ClaimValor
iss e subO seu client_id.
audFixo: https://recrutamento.mindsight.com.br/ (sem o tenant).
jtiUUID4 novo a cada assertion, usado uma única vez.
iatAgora, em Unix epoch. Não pode ser mais de 5 minutos no passado.
expiat + 3600. Não pode passar de 60 minutos à frente do relógio do servidor, nem estar no passado.

2. Troque por um access token

POST https://recrutamento.mindsight.com.br/{tenant}/external-api/v1/oauth/token/
application/x-www-form-urlencoded 
grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer
client_assertion_type=urn:ietf:params:oauth:client-assertion-type:jwt-bearer
client_assertion=<o JWT assinado do passo 1>
Resposta 200 
{
  "token_type": "Bearer",
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_in": 3600
}

Exemplo em Python

Python 
import time
from uuid import uuid4

import jwt  # pip install PyJWT cryptography
import requests

TENANT = "seu-tenant"
CLIENT_ID = "YOUR_CLIENT_ID"
API_BASE = f"https://recrutamento.mindsight.com.br/{TENANT}/external-api/v1/"
PRIVATE_KEY_PEM = open("private.pem").read()  # em produção, carregue de um gerenciador de segredos


def build_client_assertion() -> str:
    now = int(time.time())
    claims = {
        "iss": CLIENT_ID,
        "sub": CLIENT_ID,
        "aud": "https://recrutamento.mindsight.com.br/",
        "iat": now,
        "exp": now + 3600,
        "jti": str(uuid4()),
    }
    return jwt.encode(claims, PRIVATE_KEY_PEM, algorithm="RS256", headers={"alg": "RS256", "typ": "JWT"})


def get_access_token() -> str:
    response = requests.post(
        f"{API_BASE}oauth/token/",
        data={
            "grant_type": "urn:ietf:params:oauth:grant-type:jwt-bearer",
            "client_assertion_type": "urn:ietf:params:oauth:client-assertion-type:jwt-bearer",
            "client_assertion": build_client_assertion(),
        },
        timeout=30,
    )
    response.raise_for_status()
    return response.json()["access_token"]


session = requests.Session()
session.headers["Authorization"] = f"Bearer {get_access_token()}"

Erros do endpoint de token

Todos os problemas com o JWT (expirado, iat antigo, exp distante, aud errado, assinatura inválida, texto qualquer) devolvem o mesmo erro, sem detalhe. Para depurar, confira relógio da máquina, aud, client_id e se a chave privada corresponde à pública enviada.

SituaçãoStatusCorpo
Qualquer problema no client_assertion ou em client_assertion_type400{"error": "invalid_client"}
grant_type diferente do esperado400{"error": "unsupported_grant_type"}
URL sem a barra final (oauth/token)403Página HTML de erro (não é JSON)

Revogar um token

Opcional. Revoga o token em uso ou outro token seu. Depois de revogado, o token passa a responder 401.

POST https://recrutamento.mindsight.com.br/{tenant}/external-api/v1/oauth/revoke/
application/x-www-form-urlencoded 
token=<access_token>
token_type_hint=access_token   # opcional

Resposta 200 com corpo {}.

Chave pública do servidor

Devolve a chave pública do servidor no formato JWK (kty, alg, use, n, e), útil para validar a assinatura dos access tokens emitidos. Não exige autenticação.

GET https://recrutamento.mindsight.com.br/{tenant}/external-api/v1/oauth/server-public-key/
ⓘ
O token vale 1 hora

Não há refresh token: ao expirar, gere um novo client_assertion (com jti novo) e peça outro access token. O mais simples é um token por execução da sua rotina.

4. Listar oportunidades

Retorna as oportunidades (vagas) do tenant, da mais recente para a mais antiga. É também a única forma de ler uma vaga específica.

⚠
Sem expand, o campo simplesmente não existe

Sem ?expand=request a chave request nem aparece na resposta. Um nome desconhecido em expand (ex.: ?expand=foo) é ignorado sem erro, então uma letra trocada passa despercebida: confira se a chave esperada veio.

⚠
Campos desconhecidos são ignorados em silêncio

Enviar work_model, hire_model ou status na criação devolve 201, mas esses valores não são aplicados (a vaga fica com work_model/hire_model nulos e IN_PROGRESS). Só use os cinco campos da tabela.

ⓘ
Não há como editar nem excluir pela API

Esta API externa só tem criação e leitura de oportunidades. Para corrigir ou remover uma vaga criada por engano, use a plataforma. Em ambiente de teste, prefixe os nomes (ex.: TESTE-) para encontrá-las depois com ?search=.

⚠
Quem desiste some da lista

Candidatos podem desistir na etapa Contratados. Uma chamada feita antes da desistência os incluía; as chamadas seguintes não. Se você grava os contratados no seu sistema, compare a cada sincronização e trate o desaparecimento como saída.

Vaga sem contratados devolve 200 com count: 0. Vaga inexistente devolve 404 com {"message": "Vaga não encontrada."}.

9. Receita completa em Python

Um cliente enxuto que reaproveita o get_access_token() do passo 2, percorre todas as páginas e lê uma vaga com seus campos expandidos.

Python 
def paginate(session, path, **params):
    # Percorre todas as páginas e devolve todos os itens.
    url = f"{API_BASE}{path}"
    while url:
        response = session.get(url, params=params, timeout=30)
        response.raise_for_status()
        if "application/json" not in response.headers.get("Content-Type", ""):
            raise RuntimeError(f"Resposta não é JSON: confira a barra final em {url}")
        payload = response.json()
        yield from payload["results"]
        url, params = payload["next"], {}  # o next já carrega os parâmetros


def get_job_posting(session, job_id, expand="request"):
    # Não existe GET /job-postings/{id}/, então usamos a busca por id.
    for job in paginate(session, "job-postings/", search=job_id, expand=expand):
        if job["id"] == job_id:
            return job
    return None


def create_job_posting(session, name, positions, **optional):
    # optional aceita description, manager_id e recruiter_id.
    response = session.post(
        f"{API_BASE}job-postings/",
        json={"name": name, "positions": positions, **optional},
        timeout=30,
    )
    if response.status_code == 400:
        raise ValueError(response.json())
    response.raise_for_status()
    return response.json()["id"]


# Lê a requisição de vaga da oportunidade 129

10. Segurança e operação

⚠
Nunca exponha sua chave privada

Guarde-a em um gerenciador de segredos ou variável de ambiente. Nunca em repositório git, notebook compartilhado, JavaScript de navegador ou logs.

Boas práticas

  • Um token por execução da sua rotina; reautentique no início em vez de guardar tokens entre execuções.
  • Revogue o token ao terminar, se a sua política exigir (oauth/revoke/).
  • Os dados de candidatos (e-mail, telefone, e CPF/RG quando habilitados) são pessoais: aplique a LGPD ao armazená-los.
  • Trate respostas fora do padrão: valide Content-Type e o status antes de ler o JSON.

Rotacionando o par de chaves

Se a chave privada for comprometida, gere um par novo e envie a chave pública nova ao suporte da Mindsight, que atualizará o seu client_id.
